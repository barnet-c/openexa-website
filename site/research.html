04Four constantsWhat never changes

The research contribution is four constants.

  1. Agents decide. Code executes.

    The top four layers estimate and reason; the bottom four are deterministic. The boundary between them is a typed schema.

  2. No single agent sees the whole job.

    Each agent is scoped to one gate and does one thing. Its failure is local and its output is a proposal until something downstream permits it.

  3. Nothing an agent believes can move what it is not permitted to.

    Capabilities are held per agent and per tool, enforced by the runtime rather than by the model’s good behavior.

  4. Anything that settles is written to a ledger nobody can edit.

    Append-only, hash-chained, replayable — and written only after an independent counterparty confirms.
